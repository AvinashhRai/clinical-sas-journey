# Datasets

Synthetic datasets used for Clinical SAS learning and portfolio projects.

## Structure

- `raw/` — source-style synthetic data
- `sdtm/` — future/current SDTM datasets
- `tlf/` — future table, listing and figure inputs/outputs

Analysis datasets will be added later when they are actually covered in the training.

No real patient, employer, or confidential clinical-trial data should be stored here.
