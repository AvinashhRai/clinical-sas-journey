# Clinical SAS Journey

A hands-on learning repository documenting my transition from pharmaceutical quality assurance to Clinical SAS Programming and Clinical Data Management.

## About Me

I am a B.Pharm graduate currently working as an IPQA Officer in a GMP-regulated pharmaceutical manufacturing environment.

I am building practical skills in Base SAS, SQL, clinical data management, CDISC and clinical trial data programming.

## Learning Path

- Base SAS Programming
- DATA and PROC Steps
- SAS Libraries and Datasets
- Data Cleaning and Transformation
- IF / ELSE and WHERE Logic
- KEEP / DROP
- PROC SORT
- MERGE and SQL
- Clinical Trial Data Concepts
- CDISC Fundamentals
- SDTM
- Tables, Listings and Figures (TLFs)
- Clinical Data Validation

## Progress

### Day 02 — Completed

### Day 03 — Completed

### Day 04 — Completed
Practical dataset manipulation using SET, WHERE, IF/ELSE, KEEP/DROP, AND/OR and IN.
